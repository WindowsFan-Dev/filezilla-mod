# 🎮 FTP FileZilla Mod (Windows + PS3 HEN Suite)

Suite de transferencia FTP optimizada para **PlayStation 3 (HFW / HEN)** y **Windows**, diseñada para enviar juegos y respaldos sin configuraciones complicadas ni cortes de conexión.

## ✨ Características principales

* **Cliente Windows inteligente (`FileZilla.Mod.exe`):**
  * Arrastra y suelta archivos `.iso` o `.pkg` para enviarlos automáticamente a `/dev_hdd0/PS3ISO/` o `/dev_hdd0/packages/`.
  * Transferencia estable a **1 hilo** para evitar bloqueos en el servidor FTP de webMAN MOD.
  * **Receptor con confirmación de identidad:** Cuando la PS3 envía un reporte o respaldo hacia el PC, Windows muestra una ventana emergente con la IP real, nombre del dispositivo y exploit activo antes de aceptar el archivo.
* **Aplicación nativa PS3 (`FileZillaMod_v1.2-beta_PS3.pkg`):**
  * Interfaz estilo **Android TV** a 60 FPS con animación de arranque y música Metal integrada.
  * **Auditoría forense de 6 puntos:** Verifica en vivo el estado de HEN, Servidor FTP (Puerto 21), webMAN MOD, Flash/Firmware, carpetas `/PS3ISO` y `/packages`, e integridad de la app.
  * Selector visual de IP del PC guardado directamente en el disco duro de la consola.
